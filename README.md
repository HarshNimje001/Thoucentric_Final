# EIC Strategy Workspace

A static website package for the EeVee Infrastructure Corporation (EIC) investment case. The site follows the strategy/report sequence: problem statement, final issue tree, Ishikawa, 5 Whys, customer logic, assumptions, investment options, decision matrix, strategic trade-off, recommendation, 3-year roadmap, KPIs/business impact, AI prompt journey, analytical guardrails, competition workflow, and Team.

## Included source artifacts

- `attachments/Ishikawa(1).drawio`
- `assets/problem_statement_hd.png`
- `assets/team/Harsh Nimje.jpeg`
- `assets/team/Krupa Raju.jpeg`
- `assets/team/Rohit Dange.jpeg`

The Draw.io files are preserved unchanged as downloadable source files. The site also includes lightweight SVG renders for in-browser viewing.

## Run locally
Open `index.html` directly, or serve the folder with any static server, for example:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080/`.

## Content discipline
The site distinguishes case facts, inferences, assumptions and recommendations. It does not claim a conventional ROI because the case does not provide sufficient station economics. The stated “30% utilization increase” is shown as a case target; any conversion to ~60% is not treated as a case fact.
